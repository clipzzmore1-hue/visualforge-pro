# VisualForge Pro — AI-Powered Video & Photo Editor

> Fully working web-based video and photo editor. More powerful than CapCut. Optimized for Instagram and YouTube creators.

## 🚀 Features

- **AI Auto-Edit** — Describe your video, let AI handle editing
- **Video Editing** — Timeline, transitions, effects, text, green screen
- **Photo Editor** — Layers, brushes, filters, AI tools
- **4K & 8K Export** — FFmpeg.wasm in browser
- **Platform Presets** — YouTube, Instagram, TikTok optimized
- **PWA** — Install on iOS/Android, works offline
- **Stripe Integration** — Free trial, no credit card required

## 🚀 Quick Start

```bash
npm run install:all
npm run dev
# Open http://localhost:5173
```
